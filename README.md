# My-Python-Projects

# 🐍 Python Basics – Logic, Calculations & User Interaction

*A hands-on project demonstrating core Python programming skills through problem-solving exercises.*

## 🔍 Overview

This repository contains my Python work from Week 6 of the Data Technician programme (Day 1 and Day 2).

The project covers the fundamentals of Python: working with variables and user input, converting data types, making decisions with `if` statements and repeating tasks with loops, then using them to solve practical, real-world problems.

---

## 🚀 Skills Demonstrated

### ✔️ Python Fundamentals

* Creating and using variables
* Displaying output with `print()`
* Collecting user input with `input()`
* Type casting with `int()` and `float()`
* Arithmetic, floor division (`//`) and modulus (`%`) operators

### ✔️ Decision Making

* `if`, `elif` and `else` statements
* Combining conditions with `and`
* Using the modulus operator to check divisibility
* Comparing values to validate user input

### ✔️ Loops & Iteration

* `for` loops with `range()`
* Nested `for` loops to build patterns
* `break` and `for ... else` to stop a loop early
* Accumulating totals inside loops

### ✔️ Practical Real-World Scenarios

I completed exercises such as:

* A reception desk greeting using a visitor's name and age
* A tile area and cost calculator
* Celsius to Fahrenheit and miles to kilometres converters
* A "lucky number" tool that adds the digits of a number
* A digit reverser for an escape room game
* An access code checker
* A divisibility checker (by 3 and 7)
* A sum of numbers from 1 to n
* A prime number checker
* A factorial calculator
* A number staircase pattern
* FizzBuzz
