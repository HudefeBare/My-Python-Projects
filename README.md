# 🐍 Python Project – Basics, Logic & Problem-Solving

*A hands-on Python project demonstrating programming fundamentals, decision making, loops, and practical problem-solving.*

## 🔍 Overview

This repository contains my Python work from Week 6 of the Data Technician programme (Day 1 and Day 2).

Across two Google Colab notebooks and a coding challenge, I practised core Python concepts including variables, user input, type conversion, conditional statements and loops.

I applied these to realistic, scenario-based tasks such as calculators, converters, number checkers and pattern printing.
